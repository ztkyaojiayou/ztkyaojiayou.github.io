AI 网关与 Agent 工程

内部大模型网关的设计取舍与工程落地

把多厂商模型收敛成一个入口之后，真正的工作才开始：认证、配额、成本、容灾、可观测这些「平台能力」怎么落地；多副本部署之后，哪些语义会悄悄失真。本系列以此为主线，讲取舍，也讲被否掉的方案。

  • 统一接入：协议兼容与准入治理
  • 多副本：配额、成本与 Key 状态的一致性
  • 流式链路：超时、重试与计费边界
  • 数据侧：用量看板与调用明细的生命周期

目标是：说清楚网关的价值为什么在治理，而不在转发。
